# 🤖 Business CopilotAI — AI Agent

A smart business assistant AI agent built with Python and Groq LLM.

## 💡 What it does
- Answers business questions conversationally
- Calculates revenue, profit and other math
- Writes professional business emails
- Remembers conversation history
- Clean browser UI built with Gradio

## 🛠️ Tech Stack
- Python
- Groq API (LLaMA 3.3 70B)
- Gradio
- Google Colab

## 🧠 Concepts Learned
- AI Agent architecture (ReAct loop)
- Tool calling and execution
- Conversation memory management
- System prompts and LLM behavior
- Building UI with Gradio

## 🚀 How to Run
1. Open the notebook in Google Colab
2. Add your GROQ_API_KEY in Colab Secrets
3. Run all cells
4. Open the Gradio public link
